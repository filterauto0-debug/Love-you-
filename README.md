# For My Love ❤️

A premium, luxury romantic website with smooth animations, glassmorphism design, and interactive features. Perfect for expressing love through a beautifully crafted digital experience.

## ✨ Features

### 🎨 Design
- **Luxury Theme**: Black, Pink, Rose Gold, and White color palette
- **Animated Gradient Background**: Floating hearts, glowing particles, stars, and soft blur effects
- **Glassmorphism UI**: Modern frosted glass aesthetic
- **Premium Typography**: Elegant Google Fonts with smooth spacing
- **Fully Responsive**: Works perfectly on all devices
- **Smooth Animations**: Fade, slide, parallax, hover effects, and page transitions

### 🎭 Interactive Sections
1. **Hero Section** - Cinematic landing with animated hearts and CTA button
2. **Love Letter** - Elegant animated envelope with personalized message
3. **Memory Gallery** - Responsive lightbox gallery with zoom effects
4. **Reasons I Love You** - Animated flip cards with custom reasons
5. **Love Counter** - Real-time days/hours/minutes/seconds together
6. **Music Player** - Floating player with controls and volume
7. **Surprise Button** - Confetti, fireworks, and floating hearts animation
8. **Proposal Section** - Romantic question with celebratory animations

### 📱 Technical Features
- HTML5 semantic markup
- Pure CSS3 with custom properties
- Vanilla JavaScript (no frameworks)
- Lazy loading for images
- SEO meta tags
- Open Graph support
- Accessibility ready
- Performance optimized
